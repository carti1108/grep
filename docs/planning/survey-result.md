# 설문 중간 결과 (응답 7개)

집계일 2026-11-25. Google Forms "업무 자료 저장과 다시 찾기 경험 설문"의 요약 화면을 그대로 옮겨 셌다. 설문 설계와 분석 계획은 가설 검증 설문 브랜치(`claude/hypothesis-validation-survey-b2fb3c`)의 `docs/planning/survey.md`에 있다. 근거 ID는 [기획 상태 문서](STATE.md) 7절의 E-92다.

> **먼저 알아 둘 것**
> - **응답이 7개뿐이다.** 분석 계획은 칸이 5명·5건 미만이면 판정을 "보류"로 두고, 결과 정리 게이트를 "본 대상 15명 이상"으로 잡았다. 이 문서의 내용은 모두 **방향을 보여 주는 첫 신호**이지 판정이 아니다.
> - **이 설문은 이전 문제 정의(다시 찾기 실패) 기준이다.** AI 도구 사용은 묻지 않았다. 그래서 지금 문제 정의(AI 도구에 자료를 넘기지 못함)에는 간접 근거로만 쓴다.
> - **표본이 치우쳐 있다.** 경력 1년 미만이 7명 중 5명이고, 지인·커뮤니티 배포라 관심 있는 사람이 더 응답했을 수 있다. 비율을 전체 사용자 수치로 쓰지 않는다.
> - 요약 화면만 봤다. 사람별 교차 분석(예: 분류하는 사람과 안 하는 사람의 실패율 비교)은 하지 않았다. 연락처 문항은 이 문서에 옮기지 않는다.

## 5. 지금 문제 정의(AI에 넘기기)에 주는 뜻

1. **N7(떠올리지 못함)에 첫 숫자가 생겼다.** 7명 중 5명이 지난 4주에 2번 이상 “저장해 둔 걸 모르고 다시 찾거나 다시 저장”했다. 다만 AI 작업 중이었는지는 모른다.
2. **같은 걸 또 저장할 때 알려 주기(F21)의 근거가 된다.** “모르고 다시 저장”이 흔하다면, 그 순간이 서비스가 “이미 있어요”라고 말할 기회다.
3. **“이것저것 써 보고 싶어서 저장”하는 사용자가 실제로 많다.** 저장 이유가 “언젠가” 5명, “곧 작업에” 0명이다. 저장할 때 용도가 없으니, 작업을 시작할 때 자료가 먼저 나타나야 한다는 저니맵의 방향과 맞는다.
4. **이미지·스크린샷이 링크만큼 많다.** 저장 형식과 다시 찾은 자료 모두에서 이미지가 많다. 인스타그램·스레드 내용을 못 가져올 경우를 생각하면 스크린샷 글자 읽기(F16)의 우선순위를 다시 볼 이유가 된다.
5. **비어 있는 것:** AI 도구 사용 빈도, AI에게 일을 시킬 때 저장한 자료를 넣으려 했는지는 이 설문으로 알 수 없다.
